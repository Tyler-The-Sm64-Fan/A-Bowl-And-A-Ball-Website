Install help

Windows
  1. Download the Windows zip, right-click it and choose Extract All.
  2. Open the folder and double-click A Bowl And A Ball.exe.
  3. If SmartScreen says “Windows protected your PC”, click More info, then Run anyway. This appears for games from small developers that are not code-signed.
  4. For HDR, turn on HDR in Windows (Win + Alt + B) and tick HDR output in the game settings.
Linux
  1. Download and extract the Linux zip.
  2. Make the game file executable: right-click it, Properties, Permissions, “Allow executing”, or run chmod +x on it.
  3. Double-click it, or start it from a terminal.
  4. You need Vulkan graphics drivers (Mesa for AMD and Intel, the NVIDIA driver for NVIDIA) and PulseAudio or PipeWire.
Android
  1. Download the APK on your phone, or copy it there from a computer.
  2. Open the file. If asked, allow Install unknown apps for your browser or file manager, then tap Install.
  3. If Play Protect warns about an unknown app, tap Install anyway.
  4. The first time you record, Android asks for All files access so videos can be saved to a recordings folder. The game works without it, but recordings cannot be saved.
Controls

Mouse or touch: click or tap SPAWN BALL. Keyboard: Space or Enter to spawn, 1-9 and 0 to buy, Esc for settings, F9 to record, F11 for fullscreen. Controller: A to spawn, Start for settings, B to go back.
